# School-Management-System
A simple console-based School Management System developed using Java and the MVC (Model-View-Controller) architecture.
This project helps manage student and teacher details efficiently through a structured and organized design.

Features
Add and manage student details
Add and manage teacher details
Object-Oriented Programming concepts implementation
MVC architecture implementation
Repository pattern for data handling
Simple and user-friendly console interface

Technologies Used
Java
Eclipse IDE
OOP Concepts
MVC Architecture
