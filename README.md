# School-Management-System
A simple console-based School Management System developed using Java and the MVC (Model-View-Controller) architecture.
This project helps manage student and teacher details efficiently through a structured and organized design.

Features--  

1.Add and manage student details  
2.Add and manage teacher details  
3.Object-Oriented Programming concepts implementation  
4.MVC architecture implementation  
5.Repository pattern for data handling  
6.Simple and user-friendly console interface  

Technologies Used--  

Java,  
Eclipse IDE,  
OOP Concepts,  
MVC Architecture.  

Concepts Used--  

Inheritance,  
Encapsulation,  
Polymorphism,  
Abstraction,  
Collections,  
MVC Design Pattern.
